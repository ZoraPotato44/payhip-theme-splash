# Payhip Splash Theme

A custom, neon-styled theme for Payhip, featuring custom fonts and a dark, modern aesthetic.

## Features
- **Custom Typography:** Uses custom 'Splash' fonts for a unique look.
- **Neon Aesthetic:** Dark background with vibrant pink and blue accents.
- **Interactive Elements:** Responsive hover effects for buttons.

## Installation
1. Log in to your [Payhip](https://payhip.com/) account.
2. Go to your **Store Builder**.
3. Navigate to the **Settings** or **Custom CSS** section.
4. Copy the code from `style.css` in this repository and paste it into the CSS editor.
5. Save and Publish your changes.

## Customization
- To change colors, modify the variables under the `:root` section in `style.css`.
- Colors currently used:
  - Background: `#0d0e14`
  - Neon Pink: `#ff007f`
  - Neon Blue: `#00f2ff`
